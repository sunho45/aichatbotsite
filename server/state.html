Server State

200

The server is reachable and ready to respond.

What this status means

400
Bad Request. The server could not understand the request.
401
Unauthorized. Sign-in or a valid token is required.
403
Forbidden. The request was understood, but access is not allowed.
404
Not Found. The requested page or resource does not exist.
500
Server Error. The server hit an unexpected problem.
