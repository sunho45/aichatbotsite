서버 모듈 설계도

이 문서는 기존 server.js 파일을 작은 모듈로 나눈 뒤, 각 모듈이 어떤 역할을 하는지 한눈에 볼 수 있도록 정리한 지도입니다. 요청이 어디로 들어오고, 실제 기능 로직이 어디에 있으며, 어떤 유틸리티가 전체 서버를 보조하는지 확인할 때 사용하면 됩니다.

모듈 지도

현재 서버는 하나의 흐름처럼 동작합니다. server.js가 앱을 시작하고, 미들웨어가 요청을 준비하며, 라우트가 기능을 선택합니다. 서비스는 외부 API 작업을 처리하고, 유틸리티는 반복되는 공통 로직을 main 파일 밖으로 분리합니다.

전체 서버 구조

시작

server/server.js

Express 앱과 HTTP 서버를 만듭니다. 미들웨어, API 라우트, 정적 프론트엔드 파일, 에러 핸들러, 웹소켓 업그레이드를 연결한 뒤 PORT에서 서버를 실행합니다.

설정

config/runtime.js

.env를 읽고 실행 환경 값, API 키, provider URL, 업로드 제한, 파일 경로를 export합니다.

config/protocol.js

metadata에서 사용하는 서버 이름, protocol revision, transport header, API tool 설명을 정의합니다.

요청 계층

middleware/transportHeaders.js

API 응답에 custom protocol header를 추가합니다.

routes/api.js

/api/protocol, /api/metadata, /api/chat, /api/voice 라우트를 정의합니다.

routes/reactApp.js

브라우저 이동을 위해 React build 파일을 제공하고, build가 없으면 명확한 에러를 반환합니다.

middleware/errorHandlers.js

404, body 크기 초과, 잘못된 JSON, 일반 서버 에러를 JSON 응답 형태로 정리합니다.

기능 로직

services/chatService.js

채팅 메시지를 검증하고 system prompt를 만든 뒤 OpenRouter를 호출하며, 응답을 정리합니다.

services/voiceService.js

텍스트 입력을 검증하고 ElevenLabs를 호출한 뒤 오디오를 브라우저로 stream합니다.

services/protocolService.js

서버 tool과 endpoint를 설명하는 metadata JSON 문서를 만듭니다.

websocket/chatSocket.js

/api/chat WebSocket upgrade를 처리하고 JSON 메시지를 파싱하며, 채팅 상태, 답변, 에러를 보냅니다.

websocket/frame.js

chat socket에서 사용하는 낮은 수준의 WebSocket frame을 읽고 씁니다.

요청 흐름

서버 시작 server.js가 runtime.js를 불러오고 Express를 만든 뒤, 미들웨어와 라우트를 연결하고 HTTP 서버를 시작합니다.
미들웨어가 요청 준비 기능 라우트가 실행되기 전에 CORS, JSON body parsing, URL-encoded body parsing, protocol header 처리가 먼저 실행됩니다.
라우트가 기능 선택 routes/api.js는 chat, voice, metadata 요청을 알맞은 service로 보냅니다. routes/reactApp.js는 frontend navigation을 처리합니다.
서비스가 실제 작업 수행 chat 요청은 OpenRouter를 호출하고, voice 요청은 ElevenLabs를 호출하며, metadata 요청은 로컬 JSON 설명 문서를 만듭니다.
유틸리티가 공통 동작 지원 작은 helper들이 메시지 정규화, persona prompt 생성, URL 계산, 수정 시간 읽기, async route handler wrapping을 담당합니다.
에러는 한 곳에서 마무리 예상하지 못한 route error는 handleAsync를 통해 middleware/errorHandlers.js로 전달되어 일관된 JSON 응답으로 정리됩니다.

HTTP API 경로

경로 처리 모듈 목적
GET /api/protocol routes/api.js to protocolService.js protocol metadata를 반환합니다.
GET /api/metadata routes/api.js to protocolService.js 같은 metadata를 다른 이름의 endpoint로 반환합니다.
GET /.well-known/ai-server.json server.js to protocolService.js 사이트 root에 있는 public discovery endpoint입니다.
POST /api/chat routes/api.js to chatService.js 채팅 메시지를 OpenRouter로 보내고 JSON 답변 하나를 반환합니다.
POST /api/voice routes/api.js to voiceService.js 텍스트를 ElevenLabs로 보내고 오디오를 stream합니다.

WebSocket 경로

경로 처리 모듈 메시지 흐름
WS /api/chat websocket/chatSocket.js and websocket/frame.js upgrade 요청을 처리하고, frame을 decode하고, JSON을 parse한 뒤 thinking 상태를 보냅니다. 이후 chat service를 호출하고 reply 또는 error frame을 보냅니다.

유틸리티 모듈

파일 사용 위치 기능
utils/asyncHandler.js server.js, routes/api.js async Express handler를 감싸고 에러를 error middleware로 전달합니다.
utils/messages.js services/chatService.js 메시지에 유효한 내용이 있는지 확인하고 text/image content를 정규화합니다.
utils/persona.js services/chatService.js 기본 system prompt와 선택적 persona.type.yaml 설정을 합칩니다.
utils/urls.js services/protocolService.js request header와 proxy header를 사용해 HTTP 및 WebSocket base URL을 만듭니다.
utils/files.js services/protocolService.js metadata에 사용할 file modified time을 안전하게 읽습니다.
